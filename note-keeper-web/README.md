# note-keeper-web

React 18 + TypeScript UI. The production build is copied into the backend JAR (and into the native image).

```bash
npm install && npm run dev
# http://localhost:3001  — proxies /api to :8080
```

A public test instance of the whole product is at [https://note.cogitor.dev](https://note.cogitor.dev).
